Capture spike — RFC #12

Measures the live path before it is committed to: a canvas composite at 720p or 1080p, recorded through MediaRecorder with CanvasCaptureMediaStreamTrack at 30 fps and an audio track, for a set duration. Run it in each browser you care about and keep the JSON. Serve it with npm run spike:capture — the camera needs a secure context, and localhost counts.
